# Screen Recording Checklist
## Odoo Hackathon Submission - Preventive Maintenance System

---

## PRE-RECORDING SETUP

### Technical Setup
- [ ] Clean browser window (no extensions visible)
- [ ] Browser zoom set to 100%
- [ ] Screen resolution: 1920x1080 or higher recommended
- [ ] Microphone tested and audio levels checked
- [ ] Screen recording software configured (OBS, Loom, QuickTime, etc.)
- [ ] Test data prepared in the system
- [ ] Backend API running and accessible
- [ ] Application running in development or production mode

### Content Preparation
- [ ] Review the voice-over script
- [ ] Practice the demo flow at least once
- [ ] Prepare sample data:
  - [ ] Multiple maintenance requests in different statuses
  - [ ] Equipment entries
  - [ ] Categories configured
  - [ ] WorkCenters set up
  - [ ] User with multiple roles (if possible)
- [ ] Clear browser cache if needed
- [ ] Have login credentials ready

---

## RECORDING FLOW

### 1. Introduction (0:00-0:15)
- [ ] Show application title/logo or login page
- [ ] Speak introduction clearly
- [ ] Pause briefly after introduction

### 2. Authentication (0:15-0:40)
- [ ] Show login page (split-screen design)
- [ ] Demonstrate form validation (try invalid email)
- [ ] Click "Sign up here" link
- [ ] Show registration form
- [ ] Fill form or show validation errors
- [ ] Return to login and demonstrate successful login
- [ ] Show redirect to dashboard

### 3. Dashboard (0:40-1:20)
- [ ] Let dashboard load completely
- [ ] Hover over each of the 5 metric cards
- [ ] Point out percentages and progress bars
- [ ] Show Quick Stats section
- [ ] Show Status Distribution section
- [ ] Mention loading animations if visible

### 4. Kanban Board (1:20-2:30)
- [ ] Navigate to Maintenance Request page
- [ ] Show the 4 columns clearly
- [ ] Hover over a task card to show details
- [ ] Point out task information (type, priority, equipment, etc.)
- [ ] **IMPORTANT**: Drag a task from one column to another
- [ ] Show the status update happening
- [ ] Point out total task count
- [ ] Show empty state if any column is empty

### 5. Configuration Module (2:30-3:10)
- [ ] Click Configuration in sidebar
- [ ] Show Equipment Config table
- [ ] Navigate to Categories
- [ ] Navigate to WorkCenters
- [ ] Point out table features (sticky headers, etc.)
- [ ] Show edit buttons (even if not functional in demo)

### 6. Profile Module (3:10-3:50)
- [ ] Click Profile in sidebar
- [ ] Show sidebar with user info
- [ ] Click through different tabs:
  - [ ] Overview
  - [ ] My Tasks (if available)
  - [ ] Vendor Portfolio (if available)
  - [ ] Company Dashboard (if available)
  - [ ] My Team (if available)
  - [ ] Maintenance (if available)
  - [ ] Settings
- [ ] Point out role-based visibility

### 7. UI/UX Highlights (3:50-4:10)
- [ ] Show sidebar collapse/expand
- [ ] Navigate between different pages
- [ ] Show smooth transitions
- [ ] Demonstrate responsive design (resize window if possible)
- [ ] Show a loading state if possible

### 8. Technical & Conclusion (4:10-4:35)
- [ ] Summarize key features
- [ ] Mention technical stack
- [ ] Thank viewers
- [ ] End with clear closing

---

## POST-RECORDING

### Review
- [ ] Watch the entire recording
- [ ] Check audio quality and clarity
- [ ] Verify all features are visible
- [ ] Ensure mouse movements are clear
- [ ] Check that drag-and-drop is clearly shown
- [ ] Verify timing matches script (4-6 minutes)

### Editing (if needed)
- [ ] Trim any long pauses
- [ ] Add transitions between sections
- [ ] Add text overlays for key features (optional)
- [ ] Add background music (optional, keep it subtle)
- [ ] Add title card at beginning (optional)
- [ ] Add end card with contact info (optional)

### Export
- [ ] Export in high quality (1080p minimum)
- [ ] Use MP4 format for compatibility
- [ ] Keep file size reasonable (<500MB if possible)
- [ ] Test playback on different devices

---

## TIPS FOR SUCCESS

1. **Speak Clearly**: Enunciate words, especially technical terms
2. **Pace Yourself**: Don't rush - allow time for UI to load
3. **Show, Don't Tell**: Let the UI speak for itself with brief pauses
4. **Highlight Key Features**: Use mouse hover and brief pauses to draw attention
5. **Practice First**: Do a dry run to identify any issues
6. **Stay Calm**: If something doesn't work, smoothly move on
7. **Be Enthusiastic**: Show passion for your project
8. **Keep It Concise**: Aim for 4-6 minutes total

---

## COMMON ISSUES TO AVOID

- ❌ Rushing through features
- ❌ Not showing drag-and-drop clearly
- ❌ Poor audio quality
- ❌ UI elements too small to see
- ❌ Long loading times without explanation
- ❌ Clicking too fast
- ❌ Forgetting to show key features
- ❌ Background noise or distractions

---

## BACKUP PLAN

If something goes wrong during recording:
- Have a backup browser session ready
- Keep notes of timestamps for easy editing
- Record in segments if needed (can be edited together)
- Have a simplified version of the script ready
